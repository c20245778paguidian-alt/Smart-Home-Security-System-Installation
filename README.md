# SafeHaven | Smart Home & Security Solutions

**Live site:** https:// c20245778paguidian-alt!.github.io/YOUR-REPO/

## About

SafeHaven is an interactive landing page and turnkey solution showcase designed for homeowners, short-term rental hosts, and small commercial business owners looking to install custom smart security and automation hardware. It features a dynamic cost estimator tool that allows prospective clients to build and price their custom setup in real time.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | `#020617` (Slate 950) | Page background (Dark Mode) |
| Secondary | 30% | `#1E293B` / `#0F172A` (Slate 800/900) | Bento grid section cards, navigation bar, modal layers |
| Accent | 10% | `#38BDF8` (Cyan Accent) | Buttons, interactive sliders, brand badges, focus ring glows |

### Visual style

**Style chosen:** Glassmorphism with Bento Grid layout

**Why I chose it:** The modern translucent frosted-glass aesthetic combined with structured bento cards visually communicates high-tech security reliability while maintaining an intuitive visual hierarchy.

### Contrast check

Body text color vs. background color: `#CBD5E1` (Slate 300) on `#020617` (Slate 950)  
Contrast ratio: **12.6 : 1** (Exceeds WCAG AAA standard of 7.0 : 1; minimum required is 4.5 : 1)  
Tool used: WebAIM Contrast Checker
